# 📱 Gusar Scanner — Мобильный терминал приёмки товаров

**Gusar Scanner** — нативное мобильное приложение (Flutter APK) для товароведов и сотрудников склада сети магазинов **Gusar (gusar.tj)**.
Приложение полностью автоматизирует процесс оприходования товаров с бумажных накладных (ТОРГ-12, счета-фактуры), товарных и кассовых чеков с прямой интеграцией в учетную систему магазина и складские остатки.

---

## 🌟 Ключевые возможности

### 1. 📷 Интеллектуальное сканирование накладных и чеков
- Многостраничная съёмка (объединение листов 1, 2, 3... в один документ).
- Импорт файлов (PDF, JPG, PNG) напрямую из галереи или через функцию «Поделиться» из WhatsApp/Telegram.
- Гибридный OCR:
  - **Офлайн (Google ML Kit)** — мгновенное извлечение базового текста без интернета.
  - **Vision AI (Gemini 1.5 Flash)** — понимание сложных таблиц, мелкого шрифта, рукописных пометок и специфических букв таджикского алфавита (`ғ, ӣ, ӯ, ҳ, ҷ, қ`).

### 2. ⚡ Мгновенная привязка товаров (Zero-friction Item Mapping)
- **Scan-to-Bind:** не привязан товар? Просто наведите камеру на штрихкод коробки на полке — приложение найдет товар в базе `gusar.tj` и навсегда свяжет его с наименованием поставщика.
- **Обучаемый словарь синонимов:** со второй недели 95%+ позиций связываются автоматически без участия человека.
- **AI-подсказки:** 3 наиболее вероятных товара из каталога с указанием процента совпадения (выбор в 1 клик).
- **Создание новинки за 10 секунд:** если товара еще нет в каталоге, карточка создается прямо у рампы разгрузки с автоматическим заполнением цены закупки и штрихкода.

### 3. 🔍 Физическая сверка коробок и штрихкодов
- Потоковый сканер EAN-13, EAN-8, Code 128, DataMatrix.
- Поддержка **весовых штрихкодов (префиксы `20...29`)** с автоматическим извлечением граммов/килограммов.
- Звуковая и вибро-индикация: подтверждение совпадения и громкий сигнал тревоги при пересорте.

### 4. 💰 Финансовый контроль и безопасность
- **Математическая валидация:** `Количество × Цена = Сумма` с точностью до 1 дирама.
- **Price Alert:** предупреждение о скачке закупочной цены по сравнению с прошлой поставкой.
- **Контроль маржинальности:** предупреждение, если цена закупки превысила цену розничной продажи на витрине.
- **Защита от повторной приёмки:** проверка по базе накладных `gusar.tj` для исключения задвоения остатков.

### 5. 📑 Акт расхождений и цифровая роспись
- Фотофиксация бракованного или поврежденного товара.
- Сенсорная роспись водителя-экспедитора пальцем на экране смартфона.
- Генерация официального PDF-акта и отправка в мессенджеры в один клик.

### 6. 🚀 Автосборка APK и самообновление
- **GitHub Actions CI/CD:** при каждом пуше в ветку `main` или создании релиза GitHub автоматически компилирует релизный `app-release.apk`.
- **In-App Self-Update:** при запуске приложение само проверяет наличие новой версии на GitHub Releases и предлагает обновиться без участия администратора.

## 🛠️ Стек технологий
- **Фреймворк:** Flutter 3.24+ / Dart
- **Локальный OCR:** Google ML Kit Text Recognition
- **Облачный Vision AI:** Google Gemini 1.5 Flash API
- **Сканер штрихкодов:** Mobile Scanner (CameraX / ML Kit Barcode)
- **База данных:** SQLite (sqflite) — Offline-first архитектура
- **Сеть:** Dio (REST API к `https://gusar.tj`)
- **Документооборот:** PDF, Printing, Signature Pad
- **CI/CD:** GitHub Actions (автоматическая сборка APK)

## 📦 Сборка и установка APK

### Вариант 1: Скачивание готового APK из GitHub
1. Перейдите в раздел **Releases** репозитория: `https://github.com/dehagusar-png/gusar-invoice-scanner/releases`
2. Скачайте последний файл `Gusar-Scanner-latest.apk`.
3. Откройте файл на Android-смартфоне и подтвердите установку.

### Вариант 2: Локальная сборка (для разработчиков)
```bash
# Клонирование репозитория
git clone https://github.com/dehagusar-png/gusar-invoice-scanner.git
cd gusar-invoice-scanner

# Установка зависимостей
flutter pub get

# Сборка Release APK
flutter build apk --release
```
Файл появится по пути: `build/app/outputs/flutter-apk/app-release.apk`.
